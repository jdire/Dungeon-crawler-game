# Textures

Place your wall texture images here.

## Supported formats
- PNG
- JPG/JPEG
- BMP

## Wall texture
- Name your wall texture file `wall.png` (or .jpg/.bmp)
- Recommended size: 64x256 pixels (width x height)
- The texture will be tiled vertically on walls

If no texture file is found, the game will use the procedurally generated stone texture.
